## Featured concept: 3D Web Flight Simulator

**Description:** A fully browser-based 3D flight simulator concept/prototype focused on education, interaction and modular expansion.

This project demonstrates the ability to combine frontend development, 3D rendering logic, aircraft controls, simplified physics, cockpit-style interface design, guided learning scenarios and browser performance considerations.

**Use cases:**
- Educational flight simulator
- Aerodynamics demonstration
- Guided student lessons
- Free-flight exploration mode
- Flight navigation practice
- Browser-based 3D prototype
- Interactive STEM learning tool

**Main features:**
- 3D aircraft scene running in the browser
- Aircraft controls for pitch, roll, yaw and throttle
- Simplified educational physics for lift, drag, thrust and weight
- Camera system for third-person or cockpit-style views
- Basic cockpit/instrument UI concepts
- Guided scenarios and free-flight mode structure
- Modular structure for future aircraft, airports and lessons
- Performance-aware browser experience with no extra installs

**Possible stack:** HTML, CSS, JavaScript, Three.js/WebGL, modular frontend architecture, optional Node.js backend for progress, lessons or saved data.

**Case study:** [3D Web Flight Simulator](./3d-web-flight-simulator/)

## Featured concept: OBS Esports Dashboard & Overlays

**Description:** A web-based dashboard and browser-source overlay system for OBS esports productions.

**Use cases:**
- Live scoreboard overlay
- Map veto screen
- Player statistics screen
- Waiting / starting soon screen
- Team vs team head-to-head screen
- Match information overlay

**How it works:**
The dashboard lets the producer update match data in real time, while OBS displays the overlay through a Browser Source.

**Possible stack:** React, HTML, CSS, JavaScript, Node.js, Socket.io, OBS Browser Source.
