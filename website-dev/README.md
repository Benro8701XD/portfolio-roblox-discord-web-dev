# Website Dev

Proyectos de desarrollo web, landing pages, interfaces y páginas responsivas.

## Ideas de proyectos

- Portafolio personal
- Landing page
- Dashboard
- Página para negocio
- Blog simple
- Login/register UI
- Web app con API
- Sitio responsive

## Tecnologías posibles

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Next.js
- Tailwind CSS

## Formato sugerido

```md
## Nombre del sitio

**Descripción:** Qué hace la web.

**Stack:** HTML/CSS/JS, React, Next.js, etc.

**Características:**
- Responsive
- Animaciones
- Formularios
- Integración con API

**Demo:** Agregar link si existe.
```
