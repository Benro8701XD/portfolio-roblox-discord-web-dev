## Featured project: 3D Web Flight Simulator

One of my strongest web concepts is a **browser-based 3D flight simulator prototype** created for educational and interactive use.

This kind of project combines 3D graphics, aircraft controls, simplified flight physics, camera systems, cockpit-style UI, browser optimization and modular project structure. The goal is to let users test aircraft movement, understand aerodynamic forces, explore guided learning scenarios and experience flight-style interaction directly inside a web browser without extra installs.

**Core areas covered:**

- Browser-based 3D environment
- Aircraft movement and camera control
- Pitch, roll, yaw and throttle logic
- Simplified educational physics for lift, drag, thrust and weight
- Cockpit/instrument UI concepts
- Free-flight mode structure
- Guided lesson/scenario architecture
- Modular expansion for aircraft, airports and learning modules
- Performance-aware browser experience

More details: [3D Web Flight Simulator](./website-dev/3d-web-flight-simulator/)
