# Discord Bots

Ejemplos de bots para Discord usando Node.js, JavaScript o TypeScript.

## Ideas de proyectos

- Bot de moderación
- Sistema de tickets
- Comandos slash
- Logs de servidor
- Mensajes de bienvenida
- Sistema de niveles
- Bot de música
- Bot de economía
- Integraciones con APIs

## Formato sugerido

```md
## Nombre del bot

**Descripción:** Qué problema resuelve el bot.

**Tecnologías:** Node.js, discord.js, JavaScript/TypeScript.

**Funciones principales:**
- Comando 1
- Comando 2
- Automatización 1

**Cómo ejecutarlo:**
1. Instalar dependencias.
2. Configurar `.env`.
3. Ejecutar el bot.
```

> No subas tokens, claves privadas ni archivos `.env` reales.
