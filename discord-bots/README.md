# Discord Bots

Examples of Discord bots using Node.js, JavaScript, or TypeScript.

## Project ideas

- Moderation bot
- Ticket system
- Slash commands
- Server logs
- Welcome messages
- Level system
- Music bot
- Economy bot
- API integrations

## Suggested format

```md
## Bot name

**Description:** What problem the bot solves.

**Technologies:** Node.js, discord.js, JavaScript/TypeScript.

**Main features:**
- Command 1
- Command 2
- Automation 1

**How to run it:**
1. Install dependencies.
2. Configure `.env`.
3. Run the bot.
```

> Do not upload tokens, private keys, or real `.env` files.
